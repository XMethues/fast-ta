Proposed public shape

Configuration

One immutable config per TA-Lib-named definition. All Pattern configs own Candle Settings; only seven also own Penetration. Configuration creates independent streams and prepared runners.

Input

CandleInput<'a> borrows four aligned slices. Candle is the equivalent streaming tick. No timestamps or consistency repair.

Results

PatternSignal::NoMatch or Match { direction, strength }. Outer streaming Option means result availability, never match presence.

Four modes

compute owns a compact Vec; compute_into writes a checked caller slice; a prepared runner reuses allocation but resets semantic state per series; a stream alone persists state.

pub struct CandleInput<'a> { pub open: &'a [Float], pub high: &'a [Float], pub low: &'a [Float], pub close: &'a [Float] }
pub struct Candle { pub open: Float, pub high: Float, pub low: Float, pub close: Float }

pub enum PatternDirection { Bullish, Bearish }
pub enum PatternStrength { Partial, Standard, Confirmed }
pub enum PatternSignal { NoMatch, Match { direction: PatternDirection, strength: PatternStrength } }

impl CDLDOJIConfig {
    pub fn new(candle_settings: CandleSettings) -> Result<Self>;
    pub fn lookback(&self) -> usize;
    pub fn compute(&self, input: CandleInput<'_>) -> Result<CompactOutput<Vec<PatternSignal>>>;
    pub fn compute_into(&self, input: CandleInput<'_>, out: &mut [PatternSignal]) -> Result<OutputRange>;
    pub fn prepare(&self, capacity: usize) -> Result<CDLDOJIBatchRunner>;
    pub fn stream(&self) -> Result<CDLDOJIStream>;
}
